# dsh-wake · 尾波

> 「尾波」 鱼游过去了，水还在动——那点没散的动静，就是本鱼没说完的话  by.蔚蓝家的阿溟

**一句话说完，水面上还会荡开的一圈余波。**

一轮说完后，如果一段时间没人回复，就顺着语境自己再续一小段。和「主动搭话」不同：
它不按固定间隔起话头，而是**接在每一轮结束之后**——你说完、它回完，如果接下来
随机的一段时间里没人说话，它就自己往下接。

---

## 行为

```
一轮结束（turn/end）
  └─ 在 [最短, 最长] 里随机等一个时长（默认 60–120 秒）
       ├─ 这期间你说话了 → 取消等待，连续计数清零
       └─ 没人说话 → 看「最近三条对话」：
                     关键词收尾（本地）→（可选）模型收尾判断
                     → 随机闸
                     → agent.followup(一条带引导的 user 消息)
                     → DSH 照常开一轮，它顺着上文继续输出
                     → 这一轮结束，再随机等一段（直到连续次数用完）
```

- **默认关闭**，只对勾选的会话生效；
- **判断只看最近三条对话**（真人消息 + 助手回复，自己的续话不算）；
- **最多连续 N 次**（默认 3，0 = 不续），你一旦说话就重新计数；
- 每续一次都会正常走 DSH 的一轮，**会花 token**；
- 引导语会告诉模型「这是你自己想接着说，不是对方发来的消息」。

## 安装

已经装进 `desktop` profile 的话，重启 DSH 后进 **设置 → 尾波**。

手动安装（任意 profile）：

1. 把本目录放到 `<DSH_HOME>\profiles\<profile>\node_modules\dsh-wake`；
2. 在 profile 的 `package.json` 的 `dsh.profile.bundles` 里加 `"dsh-wake"`；
3. 重启 DSH。

> `package.json` 必须存成 **UTF-8 无 BOM**，否则 DSH 启动会报 `Unexpected token '﻿'`。

## 设置项

| 项 | 默认 | 说明 |
|---|---|---|
| 启用尾波 | 关 | 总开关 |
| 等待区间 | 60–120 秒 | 每次在这个区间里随机取；两端写一样就是固定值 |
| 最多连续 | 3 | 0–20；真人说话后重新计数 |
| 每次续话概率 | 100% | 0–100；本地掷骰，不花 token |
| 话题收尾就不接 | 开 | 最近三条里命中收尾词就跳过 |
| 额外结束词 | 空 | 逗号分隔，补充内置收尾词 |
| 用模型判断收尾 | 关 | 关键词没判出收尾时，再问一次会话模型「是 / 否」；会花 token |
| 续话提示词 | 见下 | 每次续话正文；宿主会再加一层说明 |
| 目标会话 | 空 | 勾谁对谁生效；活着的会话排在前面 |
| 空闲思考 | 关 | 没人说话时安静想一会儿（不往会话里发消息）；会花 token |
| 思考等待区间 | 120–300 秒 | 每次重新随机，落在区间内 |
| 继续当前事情概率 | 50% | 新话题概率 = 100% − 此值（两者合计 100%） |
| 每次空闲最多想几次 | 3 | 真人说话后重新计数 |
| 想到就说出来 | 关 | 按概率把刚想到的话直接发到会话里（会开一轮、真的出现在聊天里） |
| 说出来的概率 | 30% | 0–100；0 = 只想不说 |
| 想到就发 B站动态 | 关 | 把想法排进「刷B站」插件的动态队列，由它按互动根本原则检查后真发 |
| 发 B站 的概率 | 20% | 与「说出来」互斥：同一次掷骰，说出来优先 |

收尾判断分两层，**输入都只有最近三条对话**：

1. **关键词（本地，不花 token，默认开）**：最近三条里任意一条的**最后一句**出现收尾词
   （晚安、先这样、明天见、早点休息……）就跳过。正文中间提到这些词不会误判。
2. **模型判断（可选，会花 token，默认关）**：关键词没判出收尾时，把最近三条交给这个会话
   正在用的模型，只让它答「是 / 否」。它答「是」就跳过；答「否」、答非所问、调用失败，
   都按「没结束」继续。

默认提示词：

> 顺着刚才的话题再说一小段：如果有没讲完的细节就补上，如果没有，就自然地把话题往前推一步。

### 空闲思考

和「续话」是两条独立的腿：

- 一轮结束后，在 `[最短, 最长]` 里随机取一个时间开始想（默认 120–300 秒）；
- 想什么由概率决定：**继续当前事情** `p%`，**另想一个新话题** `(100−p)%`，两者合计 100；
- 它在本地安静地调用一次当前会话的模型，**不往会话里发消息**，想法存到
  `<DSH_HOME>\wake-thoughts.json`，设置页「最近的想法」能看；
- 一次空闲最多想 N 次（默认 3），**你一说话就取消等待并清零**；
- **想到就说**（默认关）：开启后按概率把刚想到的话直接发进会话——这会真的开一轮，
  和你平时说话一样出现在聊天里；没掷中就只安静地记在本地；
- **想到就发 B站动态**（默认关）：把想法写进刷B站插件的 `dynamic-queue`，由它每 15 秒处理，
  发之前照样过「允许发动态」和「互动根本原则」两道闸；
  **和「说出来」互斥**——同一次掷骰，先看说出来概率，再看 B站 概率，剩下的就是沉默；
- 手动「现在想一次」不受总开关限制，只思考、不自动发，方便先试。

> 思考不产生聊天消息，所以不会打断你；它只是让 AI 在你离开时仍然“想过”。


## 数据与接口

- 配置：`<DSH_HOME>\wake.json`（旧版 `continue-speaking.json` 会自动读取迁移）
- 想法：`<DSH_HOME>\wake-thoughts.json`（最近 20 条）
- 想法动态队列：`<DSH_HOME>\bili-duty\dynamic-queue\*.json`（由刷B站插件每 15 秒处理）
- 宿主路由：
  - `GET /dsh-wake/state` —— 配置、会话清单、等待中、思考中、最近想法、最近记录
  - `POST /dsh-wake/save` —— `{ config }`
  - `POST /dsh-wake/test` —— `{ sessionId }`，立刻真发一句（勾选内、活着的会话）
  - `POST /dsh-wake/think` —— `{ sessionId }`，立刻安静地想一次

## 注意

- 这是**第三方插件**，会以你的身份往会话里写 user 消息并触发模型调用；不想花 token 时记得关掉总开关。
- 空闲思考也是模型调用（虽然不发言），同样花 token；不用就关掉。
- 它只监听 `session/event` 的 `turn/end`、`user/message`、`assistant/message`，不碰工具、不改系统提示。
- 连续次数、思考次数与「最近消息」只在内存里，DSH 重启后归零/清空；想法落盘保留。
